The person wants to have the first meeting with their counterpart now: Counterparts' short, skippable getting-to-know-you conversation.

Call the Counterparts memory server's `meet` tool with no arguments (it is `mcp__counterparts__meet` when the npm install's server is connected, `mcp__plugin_counterparts_counterparts__meet` when only this plugin's is). Then follow the instructions it returns, exactly, from the introduction onward. The tool holds the meeting's script and records each step; nothing here replaces it.

If the script says you have met already, tell the person so in one line and ask whether they'd like to go through it again; if they do, follow its steps (what they answer now is stored as new memories), and if not, talk about whatever they like. If neither tool is available, say Counterparts' memory server isn't connected in this session and suggest `/counterparts:doctor`.
